# Long-term-Mortality-and-Risk-of-Chronic-Kidney-Disease-After-Severe-Malaria-Associated-Acute-Kidney-Injury

## Overview

This repository contains the deidentified participant data and data dictionary used for analyses in the study examining long-term mortality and risk of chronic kidney disease following severe malaria complicated by acute kidney injury (https://doi.org/10.1016/j.langlo.2026.103984). The materials are provided to support transparency and reproducibility of the reported analyses.

The data included in this repository are limited to analyses presented in Table 1, Figure 2, and Figure 3 of the published manuscript.

## File Structure

- **Primary_Analysis_Dataset_Mellencamp et al. 2026_Lancet Global Health.dta**  
  Deidentified participant-level analytic dataset used for the analyses presented in Table 1, Figure 2, and Figure 3

- **Primary_Analysis_Data Dictionary_Mellencamp et al. 2026_Lancet Global Health.xlsx**  
  Data dictionary describing variables included in the analytic dataset, including variable names, labels, coding, and units where applicable

## Study Description

This study evaluates long-term mortality and kidney outcomes following acute kidney injury (AKI) among Ugandan children hospitalized with severe malaria. Data were pooled from two prospective cohorts of children with severe malaria, with follow-up extending up to 15 years after the initial hospitalization.

Primary outcomes include long-term mortality, chronic kidney disease (CKD), and long-term major adverse kidney events (MAKE-LT), defined as CKD or death over follow-up. Kidney function was assessed using estimated glomerular filtration rate (eGFR).

Primary analyses were conducted using Stata (version 18; StataCorp LLC).
